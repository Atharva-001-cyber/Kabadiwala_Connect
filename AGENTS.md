# Workspace Rules & Instructions

## Strict Operational Constraints

1. **Do not push code to git without permission**:
   - Never execute `git push` or publish commits to any remote repository without explicit permission from the user.
   - Do not perform git actions (commit, push, rebase) without prior user confirmation.

2. **Do not make changes to codebase without permission**:
   - Never edit, modify, create, or delete source files in the codebase without explicit user permission.
   - Always present the proposed changes and obtain explicit approval from the user before modifying code.
